# hyperloom
a hypermedia renderer and hypertexxtile fabricator. Hyperloom is an attempt to realize my rhizomatic netrunner dreams of Xanadu and curb my Obsidian-organizational-optimization psychosis (OOOP). Hyperloom is a universalizing interface for hypermedia and promotes a senstivity to connection, something the WWW currently neglects. It allows for the spatial arrangement of a variety of media and the realization of links between them. E.g. visualizing all the hyperlinks leading out from a webpage, building the walk matrix of a web-surf session, or displaying sources from the citations of a document.

## hypertexxtile
an assemblage of hypermedia nodes with interfacing hyperlinks that provide contextual relationality.

## hypermedia
media with rhizomatic connective potential. E.g. hypertext of the WWW is text that can link to other text. I hope that Hyperloom can eventually support render the following file types: .wif, .tex, .html, .xml, .txt, .md, .qmd, .jpynb, .bib, .pdf, .docx, .png, .jpeg, .wav, .mov, .mp3, .mp4, and probably more to come...

## hyperlink
More than a one-way blind jump into hyperspace, a Hyperloom hyperlink is an informative interface between hypermedia. HTML ``<a>`` anchor elements become fully realized hyperharbors: sites through which connected hypermedia can contextualize and mediate their relationships. Rather than adopting the one-to-one principle of HTML hyperlinks, Hyperloom hyperlinks are many-to-many and inherently bidirectional. A link therefore does not take a user from one node to another, it is the realization of connection that renders hypermedia as mutually addressable co-navigable.

Hyperlinks themselves may contain text or other files, as well as metadata about the connection.

I hope to create a .texx mark-up language to function as the hyperlinking interface between hypermedia.

## modularity
Two hypertexxtiles may be put in context with each other by simply importing each of them. Hyperlinks may be created between elements of either, as well as new nodes in the new hybrid hypertexxtile.

## hyperlocality
Hyperloom allows for the fabrication of hypertexxtiles and supports several scales through which to view them. Sort of like Obsidian graph view.

### global
View of the whole hypertexxtile. Hypermedia exist on lattice points, with hyperlinks existing on the dual lattice. Allows for the easy import/creation of new nodes as well as hyperlinks. Contains the ability to realize the anchor elements leading out of a tradtional .html webpage. Sort of like Obsidian graph view.

### local
localizing on a node or link renders it as legible and shows its neighbors. Sort of like the demos of Ted Nelson's Project Xanadu.

### microlocal
completely focus on a single object with the possibility to navigate through its connections. e.g. surfing the web.
